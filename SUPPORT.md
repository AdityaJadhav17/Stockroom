# Support

Read the [README](README.md) and [development setup](docs/development.md) before opening a question. For test setup, consult [tests/README.md](tests/README.md).

After the owner publishes the repository, use GitHub issues for setup questions, reproducible defects, and feature requests. Include the SDK version, operating system, command, and error output. Remove credentials and personal data from logs.

For vulnerabilities, follow [SECURITY.md](SECURITY.md). For conduct concerns, use the private contact in [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).

The maintainer develops this portfolio project alongside other work. The project offers no support service or response-time commitment.
